## About

প্রজেক্টের উদ্দেশ্য, ব্যবহারকারী এবং মূল সুবিধার পরিচিতি।

## Features

- Bengali ও English Typography Support
- Real-Time Split-Screen Markdown Preview
- Draggable Pane Resizing
- Panel Collapse and Maximize Controls
- Mermaid Diagram Rendering
- Vector-Quality PDF Export
- Markdown File Download
- Custom Font Uploads
- Dynamic Page Counter
- Cloud Document Sharing
- OpenGraph Social Preview
- MongoDB, GitHub API Backup and Local Storage Fallback

### Typography Themes

1. Classic Serif
2. Modern Teal
3. Book / Sepia
4. Dark Obsidian
5. Minimalist Nordic
6. Rose & Poetry
7. Academic Paper
8. Cyber Terminal

প্রতিটি থিমের সংক্ষিপ্ত বিবরণ।
